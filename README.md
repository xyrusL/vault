# Vault

Vault is a private digital workspace for organizing accounts, encrypted secrets, authentication codes, temporary email addresses, notes, and security activity in one place.

It brings commonly scattered account-management tools into a focused dashboard designed for both desktop and mobile use. Sensitive information remains protected while everyday actions such as finding an account, copying a key, checking an inbox, or generating a verification code stay quick and accessible.

## Core Experience

### Secure Vault

Store API keys, access tokens, credentials, configuration values, and related private notes as encrypted records. Secrets remain hidden until deliberately revealed and can be grouped as single values or related key-value sets.

### Account Management

Keep account names, email addresses, usernames, passwords, recovery details, status, and expiration information together. Search, filter, sort, review, update, and remove account records from a unified workspace.

### Two-Factor Authentication

Create and manage time-based authentication codes alongside the accounts they protect. QR scanning and manual setup make it easier to add existing authenticator entries.

### Email Generator

Generate dedicated email addresses for registrations, testing, and account separation. Each address includes its own inbox, message history, unread status, delivery settings, forwarding options, and storage information.

### Private AI Assistant

Use the integrated assistant to navigate the workspace and perform supported account-management actions. Protected secret values are kept out of AI conversations and require controlled local access when needed.

### Encrypted Notes

Capture private notes, reminders, account context, and other sensitive information without moving it into a separate application.

### Activity History

Review important account and security events from a searchable activity timeline. Status indicators make recent and unread activity easier to identify.

### Backup and Recovery

Export protected Vault data for safekeeping and restore it when required. Backup controls keep recovery options within the same private workspace.

### Connected Services

Manage supported integrations from the Plugins area while keeping connection details and workspace controls centralized.

## Privacy and Security

Vault is designed around deliberate access to sensitive information:

- Credentials and secret values are encrypted at rest.
- Values remain concealed until explicitly revealed or copied.
- Two-factor authentication adds protection to Vault access.
- AI features do not receive raw Vault secret values.
- Activity records provide visibility into important changes.
- Backup tools support personal recovery and continuity.

Vault is intended as a private workspace. Access should be limited to trusted users, protected by a strong password, and secured with two-factor authentication.

## Responsive Workspace

The desktop experience provides a broad dashboard for reviewing and managing larger collections. The mobile experience uses app-style navigation, compact cards, bottom sheets, touch-friendly controls, and layouts designed for narrow screens.

Primary areas remain available across both experiences:

- Dashboard overview
- Vault secrets
- Accounts
- Authentication codes
- Email Generator and inboxes
- AI Chat
- Notes and plugins
- Activity history
- Backup and settings

## Purpose

Vault is for people who want one private place to manage the practical details surrounding their online identity. It reduces the need to spread credentials, authentication tools, temporary inboxes, private notes, and account records across unrelated services.
